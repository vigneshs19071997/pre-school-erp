6Findings

Nothing broken. One thing worth knowing.

Attendance default state can look like real data

On the daily "Take attendance" screen, a student who hasn't been marked yet still shows the Present button highlighted — that's a deliberate default to save taps for the common case, not a saved record. It's only visible as real data once you hit Save. Harmless, but worth a teacher knowing before they assume "green means already done."
